# Models

All trees, rocks, props and structures are generated procedurally in `js/world/models.js`
(10 tree species × variants, boulders, bushes, ferns, logs, mushrooms, reeds, cacti,
flowers, ruins, tents, cabins, towers, standing stones, arches, caves, shrines, relics).
No external model files are required. This folder is reserved for future overrides.
